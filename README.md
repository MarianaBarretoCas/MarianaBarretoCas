## About Me

I'm a Software Developer focused on **full-stack development, backend systems and process automation**.

I work with **Java and Spring Boot**, as well as **C# and .NET**, building backend services, business applications, APIs and integrations with relational databases.

On the frontend, I develop responsive and functional interfaces using **Vue, JavaScript, HTML, CSS and Tailwind CSS**, allowing me to work across both frontend and backend layers of an application.

I also develop automation solutions using **n8n** and **Automation Anywhere**, integrating APIs, webhooks, external services, data validation and business process automation. For data persistence and workflow management, I also work with **Firestore** in NoSQL-based solutions.

I'm continuously strengthening my skills in **software architecture, clean architecture, Docker and modern development practices**, with the goal of building scalable, maintainable and complete software solutions.
